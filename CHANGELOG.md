# Changelog

All notable changes to this project are listed here. Dates are in UTC.

## [0.1.0] - 2026-11-14

First public version: the home page.

### Added
- Home page in light ("Butter") and dark ("Night desk"), following the system setting, with a Day/Night toggle that remembers your choice.
- The line: a long drawing with 30 stations, one per track. Each station opens to list every module on the way (255 rows, including 40 papers for the papers lab).
- "Guess first. Then run it.": a Rust warm-up that checks your guess against output recorded from a real run.
- Interactive 404 page: draw the missing track across a torn page and a train takes you home. Quotes from people who built the field.
- A plain-words error page in place of a blank screen if rendering fails.
- Drawing kit and scripts for every picture (`art/`).

### Not yet
- Every lesson, search, the glossary and the papers lab are marked *coming soon*.
