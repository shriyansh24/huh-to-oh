# Security policy

## What this is

Huh → Oh is currently a static website: HTML, CSS, JavaScript and images served by GitHub Pages. It has no server, accounts, cookies or forms that send data anywhere. The only thing it stores is your light/dark choice, in your own browser's `localStorage`.

## Supported versions

Only the live site and the `main` branch.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Use GitHub's private vulnerability reporting (**Security → Report a vulnerability** on this repository), or contact the maintainer privately through their [GitHub profile](https://github.com/shriyansh24).

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply within a week. Once it's fixed, you'll be credited in [CREDITS.md](CREDITS.md) if you want to be.
