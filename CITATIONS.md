# Citations

## Citing this project

If Huh → Oh helped you and you want to cite it:

```bibtex
@misc{huh_to_oh,
  author       = {Singh, Shriyansh},
  title        = {Huh → Oh: learn how computers work by building them},
  year         = {2026},
  howpublished = {\url{https://github.com/shriyansh24/huh-to-oh}},
  note         = {Work in progress}
}
```

GitHub also reads [CITATION.cff](CITATION.cff) and shows a "Cite this repository" button.
