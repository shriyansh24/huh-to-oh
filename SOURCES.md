# Sources

**What this is.** What Huh → Oh learns from, is inspired by, and is built with. Each entry links to the original. Nothing from these sources is copied into this repo: course and topic lists were read for titles and scope only, and every lesson, picture and line of code here is written from scratch.

## What the curriculum aims to cover

The planned tracks aim to match or go beyond the depth and coverage of these free resources, and to teach everything they teach from first principles:

| Source | What it shows |
|---|---|
| [First Principles Approach](https://firstprinciplesapproach.dev) | Depth per chapter: diagrams, explainers, building things up from nothing |
| [Deep-ML](https://www.deep-ml.com) | The scope of machine-learning problems worth being able to implement, and a clear path through them |
| [Systems Inside (0xax)](https://0xax.dev) | How operating systems and low-level software really work |
| [Dive into Systems](https://diveintosystems.org) | A free textbook from C to the operating system, architecture and parallelism |
| [learn-inference](https://learn-inference.com) | Inference engineering: serving models fast to many people |
| [tiny-llm](https://skyzh.github.io/tiny-llm/) | Building and serving a small LLM from the ground up |
| [Papers (Work at a Frontier Lab)](https://workatafrontierlab.com/papers) | Reading landmark papers and implementing them, the model for the papers lab |
| [Machine-Learning-Library](https://github.com/victor-explore/Machine-Learning-Library) | Machine-learning algorithms implemented from scratch, a second reference |
| [learnharness](https://github.com/amosblomqvist/learnharness) | Structuring lessons so a learner and a learning tool can pick up where they left off |

## Papers lab

The planned papers lab starts from 40 papers published between 2017 and 2026, from *Attention Is All You Need* to recent work on serving and reasoning. They are listed by year and title in `src/data/stations-full.json`. The papers are linked, never reproduced.
